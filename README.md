# RICE Advanced Maths — Casio fx-CG50 add-in

The maintained RICE project source and feature documentation are in [`RICE_Advanced_Maths/`](./RICE_Advanced_Maths/README.md).

RICE is a visible `.g3a` add-in launched from the fx-CG50's existing Main Menu. It does not replace the calculator operating software or modify Casio built-in apps. See the project README for navigation, mathematical scope, installation and limitations.

GitHub Actions runs strict host maths/keypad tests and then builds the fx-CG50 binary. The downloadable build artifact is named `RICE-fx-CG50`.
